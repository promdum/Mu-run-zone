# MU RUN ZONE

เว็บชุมชนวิ่งเพื่อสุขภาพของนักศึกษาและบุคลากรมหาวิทยาลัยมหิดล วิทยาเขตศาลายา

- ลีดเดอร์บอร์ดคณะครบทุกหน่วยงาน พร้อมแรงค์บรอนซ์ถึงตำนาน จากระยะที่อนุมัติแล้ว
- Runfeed รายบุคคล พร้อมสถานะ Verified / Pending และรูปหลักฐาน
- ลงทะเบียนและเข้าสู่ระบบด้วยรหัสนักศึกษาหรือบุคลากรมหิดล
- แผงผู้ดูแลสำหรับอนุมัติ แก้ไขระยะทางและเวลา หรือลบรายการที่ทุจริต

เริ่มจากข้อมูลว่าง ไม่มีรายการสมมติ ข้อมูลที่ส่งจริงเก็บใน IndexedDB ของเบราว์เซอร์เครื่องนี้ บัญชีผู้ดูแลเริ่มต้นคือรหัส `6913084` รหัสผ่าน `SalayaAdmin`

```bash
npm run dev
```

เปิดที่ [http://localhost:3000](http://localhost:3000)
